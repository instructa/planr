## Transport and protocol

Launch one newline-delimited JSON-RPC server in the workspace root:

```json
{ "command": "planr", "args": ["mcp"] }
```

An explicit database goes before `mcp`: `planr --db /absolute/project/.planr/planr.sqlite mcp`. `initialize` reports protocol `2025-03-26` with tools, resources, and prompts capabilities. Supported methods are `initialize`, `ping`, `tools/list`, `tools/call`, `resources/list`, `resources/read`, `prompts/list`, and `prompts/get`. Notifications without `id` receive no response.

## Tools

Schemas are returned by `tools/list`. Unless noted, input schemas reject additional properties. Required fields follow each name in parentheses. The [generated MCP schema inventory](/docs/reference/mcp-schemas-generated) gives the complete JSON Schema for every tool, including all optional properties, types, descriptions, required arrays, `additionalProperties`, and any runtime-declared defaults or enums.

## Resources

All resources return `application/json`:

- `planr://project/map`
- `planr://project/context`
- `planr://item/{id}`
- `planr://plan/{id}`
- `planr://log/{id}`

Unknown or missing IDs produce JSON-RPC errors. Resource templates use `{id}` substitution in the URI.

## Prompts

- `planr-plan` — prepare or refine planning work;
- `planr-work` — execute one map item;
- `planr-review` — audit a review item;
- `planr-map` — inspect and coordinate the graph;
- `planr-summary` — summarize evidence-backed completion.

## Results and errors

Successful tools return MCP text content whose text is serialized Planr JSON. Tool execution failures return `isError: true` with a text JSON error object and keep the server alive. Protocol failures use JSON-RPC codes: `-32700` parse error, `-32601` method not found, `-32602` missing/invalid parameters, and `-32603` internal error.
