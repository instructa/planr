Planr is a Rust product with a pnpm workspace for distribution and documentation surfaces. Start with the repository `AGENTS.md`, respect the architecture contracts under `.planr/plans/product/planr/`, and run the checks owned by the surface you change.

## Choose your path

- [Repository setup](/docs/contributing/repository-setup) installs the supported toolchain and proves a clean checkout.
- [Architecture](/docs/contributing/architecture) names the canonical owner for each kind of change.
- [Docs authoring](/docs/contributing/docs-authoring) takes one page from draft to validated navigation.
- [Testing](/docs/contributing/testing) maps changed surfaces to focused and full gates.
- [Security and privacy](/docs/contributing/security-and-privacy) covers local-first boundaries and safe evidence.

## Contribution outcome

A contribution is ready when its implementation, tests, public documentation, and generated contracts agree. Record the commands you ran and any check you could not run; do not turn an unverified assumption into a success claim.
