Guides start from an outcome and end with an observable verification signal. They cover new products, existing-project work, autonomous goals, multi-agent coordination, review/fix loops, interruption recovery, package import/export, host hooks, and model routing.

<Callout type="info" title="Guides and reference have different jobs">
  Guides explain how to achieve an outcome. Reference pages enumerate the exact current CLI, MCP, HTTP, configuration, and data contracts used along the way.
</Callout>
