## Technical details

The plugin supplies all ten Planr workflow skills. It does not install project agents. The project installer owns only the MCP snippet and hooks.

Use `--no-mcp` if MCP is already managed elsewhere; Codex then reconciles hooks only and still writes no project roles or skills. Add `--no-hooks` to omit hooks too. Use `--force` only after reviewing the dry-run.

For a CLI-shaped prompt instead of MCP tools, run `planr prompt cli --client codex`. Continue with the shared [Agent Prompt Recipes](/docs/agents/prompt-recipes) or [full lifecycle](/docs/getting-started/full-lifecycle). The recipe above is rendered from the typed contract shared with the Agent Quickstart, landing page, and verification.
