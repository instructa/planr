## Technical details

The plugin supplies all ten workflow skills plus plugin worker and reviewer agents. The project installer writes project-scoped `.mcp.json`, standalone worker/reviewer roles, and hooks; it does not copy project skills. The dry-run also shows the equivalent `claude mcp add` command when you intentionally want user scope.

With `--no-mcp`, the standalone roles and default hooks remain while `.mcp.json` is omitted. Add `--no-hooks` to omit hooks too. Use `--force` only after inspecting the preview. For a CLI-shaped prompt, run `planr prompt cli --client claude`. Continue with the shared [Agent Prompt Recipes](/docs/agents/prompt-recipes) or [full lifecycle](/docs/getting-started/full-lifecycle). The recipe above is rendered from the typed contract shared with the Agent Quickstart, landing page, and verification.
