---
title: Cursor
description: Add project MCP, agents, skills, and hooks to Cursor.
---

From the project root:

```bash
planr install cursor --dry-run
planr install cursor
planr doctor --client cursor
```

Planr writes `.cursor/mcp.json`, Planr worker and reviewer agents, skills, and hooks. The preview also prints a Cursor deeplink for an intentional user-level MCP install.

Use `--no-mcp` when Cursor's MCP configuration is managed elsewhere, `--no-hooks` to omit hooks, or `--force` after reviewing generated-file changes. For a CLI-shaped prompt, run `planr prompt cli --client cursor`.

Continue with the shared [full lifecycle](/docs/getting-started/full-lifecycle).
