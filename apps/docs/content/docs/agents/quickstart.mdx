## Grok Build setup

Grok setup is an explicit repository opt-in rather than part of `--client all`. Follow the [Grok Build integration](/docs/integrations/grok-build) to preview and install the native project assets, then return here for the shared receipt and first `$planr` request.

## Verify the setup receipt

Do not accept “installed” as the only result. The agent must report the detected client and repository, resolved Planr binary and version, whether the project already existed, every integration path changed or preserved, plugin/skill status, structured doctor result, any reload or trust action, and the exact next `$planr` prompt.

The setup is complete only when `planr project show --json` reads the project and `planr doctor --client <client> --json` reports the real client status. A missing reload action or a preserved conflict is an honest incomplete step, not permission to overwrite configuration.

## Continue safely

- Need a plan but no implementation? Use the [planning-only recipe](/docs/agents/prompt-recipes#planning-only).
- Want bounded autonomous delivery? Follow [prepare first, execute second](/docs/agents/prompt-recipes#autonomous-work-prepare-first-execute-second).
- Prefer to run every command yourself? Use the [human Quickstart](/docs/getting-started/quickstart).
- Client tools did not appear? Follow [Troubleshooting](/docs/troubleshooting#cli-works-but-the-editor-has-no-planr-tools).
