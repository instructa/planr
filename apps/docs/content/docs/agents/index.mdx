<Callout type="info" title="One skill to remember">
  Use `$planr` and describe the outcome you want. The router chooses the stage from your words and the authoritative map state.
</Callout>

## The agent journey

1. Follow the [Agent Quickstart](/docs/agents/quickstart) and copy the setup prompt for your client.
2. Check the setup receipt and reload the client when instructed.
3. Start with one `$planr` request.
4. For long-running autonomous work, prepare the board first and start only the generated, plan-bound loop handoff.

The existing [Getting Started](/docs/getting-started) path remains the canonical manual journey. Both paths operate on the same local project, plans, map, logs, reviews, and approvals.
