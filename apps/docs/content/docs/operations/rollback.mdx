---
title: Rollback
description: Restore the last known-good documentation artifact and recover safely from product upgrades.
---

Rollback redeploys a previously verified commit with its committed lockfile and Alchemy/OpenNext configuration to the same `prod` stage. It does not rebuild an old commit with today's dependency graph or environment.

## Documentation rollback

1. Freeze promotion and record the failing artifact, deployment, time, and symptom.
2. Check out the last known-good commit, restore its matching deployment environment, and run `STAGE=prod pnpm docs:deploy`; Alchemy converges the existing `planr-docs-prod` Worker and keeps `docs.planr.so` attached.
3. Verify `/`, `/docs`, a deep route, `/api/search?query=installation`, canonical metadata, assets, and the custom 404.
4. Run the browser verifier against the restored origin and monitor platform error rates before declaring recovery.
5. Diagnose forward on a new commit. Never patch generated files or deployed Worker content in place, and never use `pnpm docs:destroy` as a rollback mechanism.

Docs content has no database migration, so a docs rollback does not touch user `.planr` data. If the deployment introduced an external service or mutable store, that change exceeded the current supported contract and needs its own reviewed recovery plan.

## Planr binary or database recovery

Do not assume a binary downgrade is safe after a newer binary has opened and upgraded SQLite. Stop all Planr processes, preserve the failed database and sanitized diagnostics, and restore the pre-upgrade `.planr/planr.sqlite` backup only as a matched recovery unit. Verify with `planr doctor --client all --json` and read-only inspection before resuming work.

Public release artifacts are immutable. Fix a defective release with a new version and accurate release notes; do not silently replace assets or reuse a version.

After recovery, update [Documentation governance](/docs/operations/documentation-governance) if the incident exposed a missing freshness trigger or runbook step.
