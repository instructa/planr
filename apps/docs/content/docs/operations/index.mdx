Operations documentation covers Planr releases, the Alchemy/OpenNext Cloudflare deployment for `docs.planr.so`, rollback, redirects, drift detection, content ownership, and freshness review.

The current docs application requires Node.js 22, the root-pinned pnpm version, a frozen lockfile install, Cloudflare/Alchemy credentials for deployment, and the complete documentation quality gate before production promotion.

## Runbooks

- [Release Planr](/docs/operations/release)
- [Versioning and migrations](/docs/operations/versioning-and-migrations)
- [Deploy the documentation](/docs/operations/docs-deployment)
- [Health and diagnostics](/docs/operations/health-and-diagnostics)
- [Rollback](/docs/operations/rollback)
- [Documentation governance](/docs/operations/documentation-governance)

Each runbook distinguishes the Planr binary from the documentation site. A healthy docs deployment does not prove that a user's local Planr database or localhost API is healthy.
