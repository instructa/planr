title: Concepts
description: Understand the objects, ownership boundaries, and state transitions behind Planr.
---

Planr separates narrative intent from authoritative execution state.

| Layer | Owns |
| --- | --- |
| Product and build plans | Scope, decisions, acceptance criteria, verification intent |
| Map | Items, links, readiness, status, picks, reviews, approvals, completion |
| Logs and artifacts | Durable progress, commands, tests, findings, screenshots, live proof |
| Context | Decisions, constraints, discoveries, capabilities, and goal contracts |
