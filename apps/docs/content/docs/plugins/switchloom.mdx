Switchloom is an optional external routing tool. Planr does not install, invoke, compile, apply, or uninstall Switchloom output. Planr reads the resulting `.planr/agents.toml` and `.planr/policy.toml`, exposes provider-neutral routes in pick packets, and records observed route evidence when workers attach it to logs.

## Verified Package

Use the exact package version that Planr has verified:

```bash
npx switchloom@0.3.2 --version
```

## Compile And Apply

Run Switchloom outside Planr, from the repository that should receive generated declarations:

```bash
npx switchloom@0.3.2 compile balanced --host codex-openai --integration planr --output balanced-planr-codex.json
npx switchloom@0.3.2 apply balanced-planr-codex.json --repository .
```

The external bundle should generate repository-local Planr declarations and Codex-native roles. After application, verify what Planr can consume:

```bash
planr agents check
planr agents list --json
```

If Codex roles changed, reload the host configuration before dispatching native `agent_type` roles. Planr never infers that a requested model, effort, role, fallback, or context fork actually ran; it records requested values separately from observed evidence.

## Work With Evidence

Continue using normal Planr commands:

```bash
planr pick --json
planr done <item-id> --summary "Implemented; reported requested profile model_routing_terra_high" --profile model_routing_terra_high
```

`--profile` records the profile the worker reports for the run. It is requested or claimed routing metadata, not proof that a host actually used that profile, model, effort, role, fallback, or context fork.

For genuine runtime proof, attach route-audit evidence that separates requested, host-resolved, and effective execution values:

```bash
planr done <item-id> --summary "Implemented with route-audit evidence" --route-audit .planr/artifacts/route-audit.json
```

Requested-only routing metadata is not effective execution proof. If the host cannot provide effective runtime evidence, keep that field unavailable rather than inferring it from `.planr/agents.toml`, `.planr/policy.toml`, or `--profile`.

## Uninstall

Removal is also external to Planr:

```bash
npx switchloom@0.3.2 uninstall --repository .
planr agents check
```

After uninstall, Planr should continue to operate without routing declarations, using its unrouted fallback behavior.
