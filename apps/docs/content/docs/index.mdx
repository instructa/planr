Planr is a local-first planning and execution coordination tool for Codex, Claude Code, Cursor, explicitly opted-in Grok Build and Pi, and generic MCP or CLI clients. It keeps product intent readable, graph state authoritative, ownership explicit, and completion backed by evidence.

## The lifecycle

Planr uses one public flow across clients:

```text
idea -> product plan -> build plan -> map -> pick -> log -> review/evidence -> recovery/package -> close
```

The map is the live source of truth. Plans preserve intent and verification context; logs and reviews prove why a state transition is safe.

<Callout type="info" title="Local by default">
  Planr stores project coordination state beside your repository. It does not require a hosted account, analytics service, or cloud content backend.
</Callout>
